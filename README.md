# Kenchain Groups × Dakwood Furniture & Interiors Pvt. Ltd.

A responsive, light-luxury architectural furniture and interior design showcase built with semantic HTML5, modern CSS3, and vanilla JavaScript.

---

## 1. Quick Start

Run the project with any local HTTP server:

```bash
# Python 3
python3 -m http.server 8000

# Node.js (npx)
npx serve .
```

Then visit `http://localhost:8000` in your web browser.

## 4. Accuracy & Compliance Notes

- **Company Profile Integrity:** Dakwood manufacturing details reflect its operating woodworking capabilities in Udupi, Karnataka. Kenchain verticals reflect verified multi-sector activities.
- **Experience Attribution:** The 25+ years experience highlight is attributed to the combined founder, technical, and multidisciplinary industry background across associate enterprises, avoiding confusion with Dakwood's incorporation date.
- **Exclusion of Hospitality:** All hotel lobbies, hotel guest rooms, restaurant, and café hospitality references have been completely removed in favor of residential furniture, cabinetry, and home interiors.
- **Illustrative Assets:** Imagery and video clips serve as illustrative concept references demonstrating design and manufacturing potential.
- **Zero Financial Claims:** No prices, budgets, loan projections, or funding amounts are displayed.
