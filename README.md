# Kenchain × Dakwood Interiors Showcase

Responsive frontend concept using plain HTML, CSS and JavaScript.

## Run it
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Use Live Server, or run `python3 -m http.server 8000` from this directory and visit `http://localhost:8000`.

## Features
- Responsive landing page in charcoal, purple and gold.
- Company overview for Dakwood Furniture & Interiors and Kenchain Groups.
- Dedicated positioning section explaining the intended strengths of the partnership: coordinated furniture and interior choices, manufacturing-backed product capability, cross-category applications, and material/finish focus.
- Interior gallery for hotel lobbies, guest rooms, restaurants, workplaces and residential spaces.
- Category filters and project detail modals.
- Five embedded HTML5 video players for interior reference footage.
- Mobile navigation.

## Accuracy notes
- Company profile language about Dakwood is based on the supplied project report. Kenchain verticals reflect the business areas supplied for the group's letterhead.
- The “why this partnership” section presents proposed differentiators, not a verified claim that the companies outperform every competitor. No competitor benchmarking was supplied.
- Video clips and gallery images are illustrative stock references, not verified completed projects by Kenchain Groups or Dakwood.
- Images and video stream from external sites and require internet access. Direct video playback availability can vary; source-page links are available on video cards.
